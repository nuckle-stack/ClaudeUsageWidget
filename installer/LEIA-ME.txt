CLAUDE USAGE WIDGET
===================

Um pequeno widget para o canto do ecrã que mostra:
  - os limites de utilização do Claude (janela de 5 horas e semanal);
  - as sessões do Claude Code abertas (CLI, app Desktop, VS Code);
  - avisos quando uma sessão termina, precisa de ti ou está a gastar depressa.


REQUISITOS
----------
  - Windows de 64 bits.
  - Claude Code já instalado e em uso (CLI, app Desktop ou extensão do VS Code).
  - Não é preciso ser administrador.


INSTALAR
--------
1. Extrai este zip para uma pasta qualquer (por exemplo, Transferências).

2. Abre o PowerShell nessa pasta (na pasta onde está este ficheiro: clica com
   o botão direito num espaço vazio > "Abrir no Terminal") e corre:

     powershell -ExecutionPolicy Bypass -File .\install.ps1 -AutoStart

   (-AutoStart faz o widget arrancar com o Windows. Podes tirá-lo.)

3. No fim, vê a linha "Limites:".
     - "Limites: OK"  -> está pronto.
     - Aviso amarelo  -> as sessões e os avisos funcionam, mas os limites (5h / 7d)
                         não. Para os ter: instala o Claude Code CLI, corre
                         'claude' num terminal e faz /login com a tua conta.
                         Depois: botão direito no widget > "Atualizar agora".

4. Reinicia as sessões do Claude Code que já estavam abertas, para passarem a
   enviar dados ao widget.

O widget é copiado para %LOCALAPPDATA%\Programs\ClaudeUsageWidget, por isso
podes apagar esta pasta depois de instalar.


USAR
----
  - O widget aparece no canto inferior direito. Arrasta-o para onde quiseres.
  - Clique: abre a lista de sessões. Clicar numa sessão traz a janela dela para
    a frente. O "x" (ao passar o rato) esconde-a até voltar a ter atividade.
  - Botão direito: Definições (auto-hello, avisos, cores), Não incomodar, Sair.
  - Também há um ícone na área de notificação, junto ao relógio.
  - Avisos: "terminou" avisa uma vez; "precisa de ti" relembra até 3 vezes.
    Se já estás a olhar para a janela da sessão, o aviso conta como visto.
    Clicar no aviso (enquanto está no ecrã) leva-te à sessão.
  - "Resumo da semana" (botão direito no widget): quanto do limite semanal
    usaste, quanto gastou cada dia, que projetos o gastaram e quantas vezes a
    janela de 5h esgotou; também a semana anterior. Quando a semana renova, o
    widget mostra o resumo da que acabou.
  - "Recentes", no fim da lista de sessões: as sessões do terminal e do VS
    Code dos últimos 7 dias que já fechaste. Um clique abre um separador novo
    do Windows Terminal (ou uma consola) na pasta dela, com a conversa
    retomada (claude --resume).
  - Cada sessão diz o que está a fazer agora ("a editar Forecast.cs", "a correr
    dotnet test"). Quando pede autorização, o aviso e a lista dizem para quê
    ("precisa de ti para correr git push").
  - Ctrl+Alt+C, em qualquer programa: salta para a sessão que está à tua
    espera há mais tempo; outra vez, para a seguinte. Sem nenhuma à espera,
    abre a lista de sessões. Muda-se (ou desliga-se) nas Definições.
  - Se um limite esgotar e o Claude continuar com uso extra (pago à parte),
    o widget avisa. Quando um limite esgotado renova, também avisa.
  - "Hoje: 9% de 14% do limite semanal", no topo da lista de sessões: o que
    sobrava da semana à meia-noite, repartido por hoje e pelos dias úteis até
    ao reset (nas Definições podes contar também os fins de semana). Se hoje
    passares a tua parte, o widget avisa uma vez.
  - "Consumo", na lista de sessões: quanto da janela de 5h (ou da semana)
    gastou cada projeto e cada sessão. É uma estimativa: reparte o uso do
    Claude Code neste PC pelo custo equivalente na API (o Opus pesa mais do
    que o Sonnet ou o Haiku). Não vê conversas no claude.ai nem outros PCs.
  - O widget lê ficheiros internos do Claude Code, que podem mudar quando o
    Claude Code se atualiza. Se deixar de os perceber, avisa uma vez ("O
    widget deixou de perceber o Claude Code"); clicar no aviso procura uma
    versão nova do widget.
  - Versões novas: o widget procura-as no GitHub de 6 em 6 horas e avisa uma
    vez. Clica no aviso (ou botão direito > "Instalar a versão…") para a
    instalar: o widget fecha-se e volta a abrir sozinho, com as tuas
    definições. Desliga-se nas Definições.
  - "45% ctx", em cada sessão: quanto do contexto da sessão está ocupado. A
    partir de 80% fica cor de laranja e o widget avisa: é altura de /compact
    ou de uma sessão nova. Com "~" à frente é uma estimativa: nas sessões da
    app Desktop e do VS Code o widget não sabe ao certo o tamanho da janela
    (200k ou 1M); passa a saber quando usares o mesmo modelo no terminal.

  Qualidade do contexto (opcional): com o plugin "token-optimizer" do Claude
  Code, cada sessão mostra também uma nota da qualidade do contexto (ex.
  "Q 72 B"), e o widget avisa quando ela degrada. Sem o plugin essa nota não
  aparece; tudo o resto funciona. O widget não depende de nenhuma skill nem
  servidor MCP.


O QUE O INSTALADOR ALTERA
-------------------------
  - Em %USERPROFILE%\.claude\settings.json: o "statusLine" e um hook
    "Notification". Antes guarda uma cópia (settings.json.bak-usage-widget-...).
    Se já tinhas um statusline, ele continua a funcionar: o do widget chama-o.
  - Cria a pasta %USERPROFILE%\.claude\usage-widget (dados e registo do widget).
  - Com -AutoStart: uma entrada de arranque em HKCU\...\Run.


DESINSTALAR
-----------
     powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall

  Remove o widget e repõe o statusline que tinhas antes.


PROBLEMAS
---------
  - Algo não funciona: botão direito no widget > "Copiar diagnóstico", e cola-o
    numa mensagem para quem te deu o widget. Diz que cópias do Claude Code o
    widget encontrou, se o statusline e o hook estão instalados, quando
    chegaram as últimas leituras, e as últimas linhas do registo. Não leva
    nomes de sessões, mensagens nem valores de variáveis (só os nomes).
    Fica também em %USERPROFILE%\.claude\usage-widget\diagnostico.txt.
    Se o widget nem arranca, corre isto para o gerar:
      %LOCALAPPDATA%\Programs\ClaudeUsageWidget\ClaudeUsageWidget.exe --diagnostics
  - O comando dá erro de política de execução ou o antivírus apaga o .exe:
    o PC tem regras da empresa contra programas não assinados. Fala com o IT.
  - O widget mostra "--": ainda não há leituras. Usa o Claude Code uma vez ou
    faz botão direito > "Atualizar agora".
  - Registo de erros: %USERPROFILE%\.claude\usage-widget\widget.log
